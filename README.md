Setup 
Click the green Code button, then Download ZIP. Extract the zip (right-click, Extract All). Don't open it from inside the zip. Open dnd-creator.html in Chrome or Edge. 
Saving Click Save character. When asked, click Choose folder and pick the Save_your_characters_here folder. Click Save character any time after that to update your character.

If you see Reconnect folder the next time you open it, click it. Your characters are not lost.

Loading

Click Load character, or drag a character file onto the page.

Important 
Use Chrome or Edge on a computer to save into the folder. Other browsers download a file instead; move it into Save_your_characters_here yourself. 
Changing a character's name, race, or class and saving asks whether to replace the old file or save as new. Save PDF opens your browser's print menu. Choose Save as PDF. 
To share a character, send the .dnd.json file to a friend. To back up, copy the Save_your_characters_here folder.
